Project Name - KhetiGPT

Project Title:

KhetiGPT — AI-Powered Personal Farming Assistant

One-line description:

KhetiGPT is an AI-assisted web platform that brings selected agricultural information and farming assistance services together through a single, simple interface.

2. MVP Features

These are the features we will actually develop in the 75-day project.

Core Features
User Registration & Login
Farmer Dashboard
AI Farming Assistant
Current & Forecast Weather
Crop Recommendation
Basic Fertilizer Guidance
Government Schemes Information
Responsive Web Interface
Important

For the initial project, do NOT add everything you saw in other agriculture apps.

For example:

❌ Crop disease detection
❌ Satellite analysis
❌ IoT sensors
❌ Live mandi prices
❌ Yield prediction
❌ Drone integration

These can remain in Future Scope.

This keeps KhetiGPT realistic for a 75-day B.Tech mini project.

3. Technology Stack

Use this as the final stack:

Category	Technology
Frontend	React.js
Programming	JavaScript
Styling	HTML5, CSS3, Tailwind CSS
Backend Runtime	Node.js
Backend Framework	Express.js
Database	MongoDB
AI	Gemini API
External API	Weather API
API Communication	REST API
Version Control	Git & GitHub
IDE	Visual Studio Code


Note

Tailwind CSS is optional where useful, but I recommend using it for the actual UI because you want a professional responsive design.
