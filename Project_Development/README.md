# KhetiGPT 🌾

## AI-Powered Personal Farming Assistant

KhetiGPT is an AI-assisted web platform designed to bring selected
agricultural information and farming assistance services together
through a single, simple, and user-friendly interface.

## Project Objective

The objective of KhetiGPT is to develop a full-stack agricultural
assistance platform that integrates AI-based conversational support,
weather information, crop recommendations, fertilizer guidance, and
government scheme information.

## Core Features

- User Registration and Login
- Farmer Dashboard
- AI Farming Assistant
- Current and Forecast Weather Information
- Crop Recommendation
- Basic Fertilizer Guidance
- Government Schemes Information
- Responsive Web Interface
